# letterbox

Mail in the terminal: IMAP accounts, and Microsoft Outlook signed into in
the browser, read in a TUI, and served to an AI agent over the Model
Context Protocol (MCP), as [paperstack](https://github.com/YPARK/paperstack)
serves papers. It runs in any terminal, Emacs's vterm among them.

Nothing works yet: this is the start.
